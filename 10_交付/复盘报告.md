# 交付复盘 · smart-outbound-platform

## 项目总结
智能外呼语音对话平台，基于 FreeSWITCH+LLM 架构设计，实现了多租户管理、对话流程画布、外呼任务调度、运营看板的完整骨架。

## 完成度
- ✅ 后端骨架：Spring Boot + JWT + JPA + Redis + RabbitMQ
- ✅ 前端骨架：Vue3 + AntDVue + AntV X6 画布
- ✅ Docker Compose 部署
- ⚠️ 真实通话链路未接（FreeSWITCH 镜像拉取失败，设计已完成）

## 简历亮点
1. **FreeSWITCH + ESL** 外呼架构设计（Docker部署、ESL事件驱动）
2. **AntV X6** 可视化对话流程画布编排
3. **Spring Boot + MySQL + Redis + ClickHouse + RabbitMQ** 完整技术栈
4. **SSE** 实时通话监控推送
5. **JWT** 多租户鉴权

## 面试话术
- 架构：FreeSWITCH 负责语音流，后端通过 ESL 事件监听通话状态，ASR→LLM→TTS 实时对话循环
- 难点：并发控制（Redis信号量）、超时降级、通话中断状态回查
- 数据：MySQL存业务，ClickHouse存通话明细分析

## 踩坑记录
1. FreeSWITCH Docker 镜像国内源拉不下来（403）
2. 多个端口被本机其他项目占用（3306/6379/5672等）
3. MySQL 8.0 需要 allowPublicKeyRetrieval=true
4. ESL Java 客户端不在 Maven 中央仓库
